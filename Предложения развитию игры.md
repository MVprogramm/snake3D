	- по минимуму ошибок (титул + дополнительные очки)

Нам нужен не просто список “что улучшить”, а **план действий по превращению проекта из прототипа в коммерческий MVP**.

Главная логика такая:

> **Сначала исправляем технические ошибки → потом улучшаем первый игровой опыт → потом добавляем удержание игрока → потом косметику/монеты → потом рекламу и публикацию.**

У тебя уже есть хороший `architecture-map.md`. Он показывает, что проект построен на React + TypeScript + Vite + React Three Fiber, а игровая логика живёт в `src/engine/`, 3D-рендер — в `src/components/` и `src/assets/`, уровни — в JSON, а тесты — через Playwright. Это важно, потому что план нужно строить вокруг текущей архитектуры, а не ломать её.

## ЧЕТЫРЕ ТИПА БОНУСОВ

### 1. БОНУСЫ ВЫЖИВАНИЯ
| Бонус                     | Эффект                                | Зачем нужен                                   |
| ------------------------- | ------------------------------------- | --------------------------------------------- |
| Дополнительная жизнь      | +1 жизнь                              | Снижает раздражение от случайной ошибки       |
| Дополнительное время      | +20 секунд                            | Спасает уровень в конце                       |
| Временная остановка роста | 20 секунд яблоки не увеличивают длину | Позволяет активно собирать еду без усложнения |
Бонусы выживания появляются по алгоритму, фиксирующему нехватку времени и жизней для завершения уровня (осложнения игрока на его пути к завершению уровня). Место появления - поблизости от головы змейки.
### 2. БОНУСЫ АЗАРТА
| Бонус           | Эффект                                                        | Зачем нужен                            |
| --------------- | ------------------------------------------------------------- | -------------------------------------- |
| Удвоение очков  | x2 очки за яблоки на 20 секунд                                | Создаёт короткий “режим атаки”         |
| Серия яблок     | каждое следующее яблоко в течение 20 секунд даёт больше очков | Заставляет игрока рисковать ради комбо |
Бонусы азарта появляются по алгоритму, фиксирующему замедление скорости набора очков без увеличения количества ошибок (потерю игроком стремления завершить уровень). Место появления - возле скопления препятствий вблизи головы змейки.
### 3. ТАКТИЧЕСКИЕ БОНУСЫ

| Бонус                  | Эффект                                                                                  | Зачем нужен       |
| ---------------------- | --------------------------------------------------------------------------------------- | ----------------- |
| Разбивание препятствий | 5–8 секунд можно ломать камни/грибы                                                     | Даёт чувство силы |
| Заморозка ежей         | ежи стоят 20 секунд                                                                     | Облегчает игру    |
| Переход через границы  | Змейка может 20 секунд уходить за ближайшую границу и появляться из-за противоположной. | Ускоряет игру     |
Тактические бонусы появляются по алгоритму, фиксирующему увеличение количества ошибок игрока и уменьшение скорости набора очков (недостаточную готовность игрока к сложности уровня). Место появления - на свободном пространстве вдалеке от змейки.
### 4. "ВАУ"-БОНУСЫ
|Бонус|Эффект|
|---|---|
|Золотое яблоко|много очков + короткий x2|
|Радужная змея|одновременно не растёт и получает x2|
|Щит|одно столкновение не убивает|
|Супер-прорыв|змея временно ломает всё на пути|
"ВАУ"-бонусы появляются по алгоритму, фиксирующему резкое уменьшение ошибок и одновременно резкое повышение скорости набора очков (повышение мастерства игрока). Место появления - возле скопления препятствий вдалеке от змейки.

Сообщение о появлении бонуса указывается в меню, так что игрок узнает об этом даже не видя самого бонуса.

Игрок может купить за набранные очки право вызвать тот, или иной бонус в любой момент игры, и тогда этот бонус будет постоянно находиться в меню до его использования. Автоматическое появление этого бонуса блокируется.

В случае покупки права вызова бонуса игрок имеет возможность комбинировать два и более бонусов.
