# Bonus Rules - Snake 3D

Документ фиксирует правила автоматического ввода бонусов в игру. Это геймдизайн-правила и рабочая спецификация для дальнейших изменений бонусов.

## Общие правила

- Автоматические бонусы проверяются при поедании каждого яблока.
- Проверка выполняется после события `food eaten`.
- Для проверки используется случайное число от `0` до `1`.
- Если случайное число меньше текущей вероятности бонуса в долях единицы, бонус вводится в игру.
- Если случайное число больше или равно вероятности, бонус не вводится.
- Одновременно в игре может быть только один автоматический бонус.
- Если на поле уже есть доступный бонус, другой автоматический бонус не запускается.
- Если действует бонусный эффект времени, жизни или очков, новый автоматический бонус не запускается.
- Один и тот же автоматический бонус не выдается дважды на одном уровне.
- После запуска бонуса на поле его эффект не применяется сразу.
- Эффект применяется только после подбора бонуса игроком.
- Динамический автоматический бонус остается доступным в течение `2` съеденных яблок.
- Если бонус не подобран за это время, он удаляется с поля.
- На старте нового уровня флаги одноразового запуска автоматических бонусов сбрасываются.

## Бонус Дополнительного Времени

- Тип бонуса: `addExtraTime`.
- Значение бонуса по умолчанию: `20000` мс, то есть `20` секунд.
- Ключевой параметр: накопительная скорость поедания яблок.
- Прогноз рассчитывает, хватит ли игроку оставшегося времени, чтобы съесть все оставшиеся яблоки.
- До поедания половины всех яблок вероятность бонуса всегда равна `5%`.
- После поедания половины всех яблок вероятность рассчитывается по прогнозу времени.
- Минимальная вероятность: `5%`.
- Максимальная вероятность: `50%`.
- Максимальная вероятность достигается, когда прогнозируемый дефицит времени равен `20` секундам.
- Отклонение от дефицита `20` секунд в любую сторону снижает вероятность по линейной шкале.
- Если прогноз отсутствует или яблок больше не осталось, вероятность равна `5%`.
- Проверка запуска пишется в протокол событием `extra time bonus probability check`.
- После успешной проверки бонус создается на свободной клетке поля.
- После запуска повторная проверка бонуса дополнительного времени на этом уровне отключается.

## Бонус Дополнительной Жизни

- Тип бонуса: `addExtraLives`.
- Значение бонуса по умолчанию: `1` жизнь.
- Ключевой параметр: накопительная скорость потери жизней.
- Проверка бонуса возможна с первого съеденного яблока.
- Прогноз рассчитывает, сколько жизней игрок может потерять до конца уровня при текущей накопительной скорости потерь.
- Минимальная вероятность: `5%`.
- Максимальная вероятность: `50%`.
- Максимальная вероятность достигается, когда прогнозируемый недостаток равен `1` жизни.
- Отклонение от недостатка `1` жизни в любую сторону снижает вероятность по линейной шкале.
- Если прогноз отсутствует, вероятность равна `5%`.
- Проверка запуска пишется в протокол событием `extra life bonus probability check`.
- После успешной проверки бонус создается на свободной клетке поля.
- После запуска повторная проверка бонуса дополнительной жизни на этом уровне отключается.

## Информационная Панель

- Красные часы показывают вероятность появления бонуса дополнительного времени.
- Красное сердце показывает вероятность появления бонуса дополнительной жизни.
- Вероятности выводятся коротко, только в процентах.
- Значения вероятностей обновляются при поедании яблока.
- Символ подарка показывает состояние доступного бонуса.
- Если бонуса на поле нет, рядом с подарком отображается `0`, а подарок неактивный.
- Если на поле появился бонус дополнительного времени, рядом с подарком мигают часы.
- Если на поле появился бонус дополнительной жизни, рядом с подарком мигает сердце.
- Активный символ бонуса имеет тот же белый цвет, что и другие активные символы информационной панели.

## Текущие Ограничения

- Правила автоматического запуска сейчас описаны для бонусов `addExtraTime` и `addExtraLives`.
- Статические бонусы из JSON-уровней могут существовать отдельно от автоматических правил.
- Автоматический бонус использует параметры из JSON-уровня, если такой тип бонуса там настроен.
- Если параметров в JSON нет, используется значение по умолчанию из правила бонуса.
- Автоматические бонусы не добавляют время или жизнь в момент появления на поле.
