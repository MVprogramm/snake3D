# Player Skill Metrics - Snake 3D

Документ фиксирует проектное правило оценки мастерства игрока через время,
затраченное на поедание яблок.

## Базовая Метрика

Основная метрика - коэффициент перерасхода времени на поедание яблока.

```text
K = фактическое время игрока / идеальное время
```

Где:

- `фактическое время игрока` - время в миллисекундах от появления нового яблока
  до его поедания змейкой;
- `идеальное время` - расчетное время прохождения кратчайшего маршрута от клетки,
  где змейка съела предыдущее яблоко, до текущего яблока;
- идеальный маршрут считается на максимально доступной скорости;
- если движущийся еж появляется на оставшемся идеальном маршруте, маршрут
  виртуальной змейки корректируется.

Событие с результатом расчета записывается в протокол как:

```text
apple time efficiency
```

Текущий формат значения:

```text
playerMs:1234;idealMs:800;overrun:1.54
```

## Оценка Уровня

Для оценки уровня используется среднее значение коэффициента по всем яблокам
уровня.

```text
K_level = среднее K по всем съеденным яблокам уровня
```

Интерпретация:

| K_level | Оценка сложности уровня для игрока |
| ---: | --- |
| `< 1.5` | уровень слишком легкий |
| `1.5-2.5` | нормальная рабочая сложность |
| `> 2.5` | уровень слишком сложный |

## Оценка Мастерства Игрока

Мастерство игрока оценивается не абстрактным рангом, а уровнем сложности,
на котором игрок показывает нормальную рабочую сложность.

```text
Мастерство игрока = сложность самого высокого уровня,
на котором K_level находится в диапазоне 1.5-2.5
```

Если игрок проходит уровень с `K_level < 1.5`, этот уровень ниже его текущего
мастерства.

Если игрок проходит уровень с `K_level > 2.5`, этот уровень выше его текущего
мастерства или требует дополнительной балансировки.

## Проектное Использование

Эта метрика нужна для:

- настройки сложности уровней;
- сравнения уровней между собой;
- оценки прогресса игрока;
- проверки, не становится ли уровень слишком легким или слишком жестким;
- будущей адаптивной выдачи подсказок, бонусов или рекомендаций уровня.

## Текущие Ограничения

- Метрика зависит от корректности расчета идеального маршрута.
- Идеальный маршрут учитывает текущие препятствия и корректируется при попадании
  движущегося ежа на оставшийся путь.
- Метрика оценивает эффективность движения к яблокам, но отдельно не оценивает
  потери жизней, рискованные решения и использование бонусов.
