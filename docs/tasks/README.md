# Task Files

Put concrete task, issue, or PRD files for this project in this directory.

Recommended naming:

```text
001-menu-stabilization.md
002-mobile-controls.md
003-level-balance.md
```

Each task file should include:

- goal;
- scope;
- files or systems likely affected;
- explicit non-goals;
- acceptance criteria;
- manual test steps.

Before coding, the agent should read `AGENTS.md`, `docs/architecture-map.md`, and the relevant file from this directory.
